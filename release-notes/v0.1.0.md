## Porthole v0.1.0

First release of Porthole as a product: the app-agnostic viewer engine for running modern Linux
GUI apps on OS X 10.9, shipped as `/Applications/Porthole.app` with a Sparkle self-updater.

Install this, then install a per-app **preset** (e.g. `mavericks-signal-desktop`), whose postinstall
runs `porthole materialize` to generate a standalone "Linux <App>.app" on your Mac.
